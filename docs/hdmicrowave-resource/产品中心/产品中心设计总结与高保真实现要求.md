# 恒达微波产品中心设计总结与高保真实现要求

更新时间：2026-09-10

## 1. 设计结论

产品中心采用“目录树 + 子分类内容 + 末级产品参数表”的结构，不采用独立产品详情页作为主要浏览路径。

用户通过左侧产品目录逐级进入分类：

```text
产品中心
└── 一级分类
    └── 二级分类
        └── 三级分类
            └── ……
                └── 最末级分类
                    └── 产品介绍 + 产品图片 + 产品参数表
```

普通产品类别的核心目标是让用户在同一个末级分类中直接比较多个产品型号和技术指标，减少移动端反复进入详情页、返回列表和拖动页面的操作成本。

分系统产品是特殊类型：后台编辑时使用单个富文本编辑器，因此前台必须以文章/新闻详情的形式展示，不能套用普通产品的“介绍卡片 + 图片组件 + 参数表”布局。

## 2. 产品目录来源与高保真强制要求

### 2.1 唯一目录来源

高保真产品目录必须以以下文件为真实数据来源：

```text
docs/hdmicrowave-resource/产品中心/第九版手册目录24.12.17.docx
```

该文档是第九版产品手册的最新目录，不能继续使用旧的手工模拟目录作为高保真正式数据源。

### 2.2 必须记住的实现要求

高保真页面加载产品目录时，必须完成以下流程：

1. 读取 `第九版手册目录24.12.17.docx`。
2. 提取目录中的章节编号、分类名称和层级关系。
3. 将目录转换为可供前端使用的数据结构。
4. 高保真页面首次加载时使用该真实数据结构渲染产品目录树。
5. 后续产品列表、面包屑、分类卡片和路由状态都应基于同一份目录数据。

禁止在高保真页面中重新手写一套与 DOCX 目录可能不一致的产品分类树。

推荐的标准数据结构：

```ts
interface ProductCatalogNode {
  id: string;
  code: string;
  name: string;
  level: number;
  parentId: string | null;
  children: ProductCatalogNode[];
  kind: "category" | "product-list" | "rich-text" | "reference";
}
```

如果使用扁平数据保存，也必须保留 `code`、`level`、`parentId` 和 `children` 重建能力。例如：

```ts
interface ProductCatalogRecord {
  id: string;
  code: string;
  name: string;
  level: number;
  parentId: string | null;
  contentType: "table" | "richText" | "reference";
}
```

### 2.3 第九版目录的一级结构

根据《第九版手册目录24.12.17.docx》，当前产品手册的主要章节为：

1. 波导、同轴元器件
2. 微波有源器件
3. 天线
4. 天线转台与伺服控制
5. 分系统集成产品
6. 微波设计参考资料

需要特别注意：

- “天线测量与微波测量”在第九版目录中不再作为独立一级章节，而是分布在第一章和第三章的相关分类中。
- “分系统产品”在最新目录中的正式名称为“分系统集成产品”。
- 第五章下包含卫星通信、气象雷达、大功率辐射、侦察与测向、FOD、SAR、测速测距、RCS、单脉冲雷达、其他天馈伺、微波测试与校准等分类。

## 3. 产品中心页面结构

### 3.1 产品中心视图

```text
顶部导航
页面标题 / 产品中心说明
可点击面包屑
┌──────────────────────────────────────────┐
│ 左侧固定产品目录树 │ 右侧分类或产品内容区域 │
└──────────────────────────────────────────┘
```

## 4. 左侧产品目录树

### 4.1 交互规则

- 支持最多五级产品分类展示。
- 点击某个分类后，只展开当前路径。
- 其他一级分类自动收缩。
- 当前分类的其他同层级分类保持收缩，避免目录无限展开。
- 点击目录树分类和点击右侧分类卡片的结果必须一致。
- 目录树中显示当前选中路径，并使用选中状态突出显示。

### 4.2 固定定位

桌面端页面滚动时，左侧产品目录固定在视窗内，便于用户持续选择分类：

```css
.product-catalog-sidebar {
  position: sticky;
  top: 84px;
  max-height: calc(100vh - 104px);
  overflow: auto;
}
```

移动端不使用固定侧栏，改为普通纵向目录区域，目录选择完成后再查看右侧内容。

## 5. 面包屑导航

面包屑必须是可交互的目录路径，而不是静态文本。

示例：

```text
首页 / 产品中心 / 波导、同轴元器件 / 常用连接波导 / 直波导
```

交互规则：

- 点击“产品中心”：返回产品中心根目录。
- 点击任意中间层级：回退到对应分类层级。
- 点击面包屑和点击左侧目录树节点必须产生相同结果。
- 当前末级分类显示为当前状态，不需要重复跳转。

## 6. 右侧内容区域

### 6.1 非末级分类

右侧显示当前分类的子分类卡片，包括：

- 子分类名称
- 子分类说明
- 是否继续进入下一级的提示

点击右侧卡片后，目录树同步展开到相同节点，面包屑同步更新。

### 6.2 普通产品末级分类

普通产品末级分类右侧展示：

1. 当前产品类别介绍
2. 产品图片区域
3. 当前类别下的全部产品参数表

产品参数表规则：

- 产品型号固定在表格最左侧。
- 规格书列固定在表格最右侧。
- 中间技术指标列允许横向滚动。
- 产品型号为可点击按钮。
- 点击产品型号弹出该型号全部技术参数。
- 不跳转单独的产品详情页。
- 规格书按钮进入询单式资料申请流程。

参数表的字段以实际产品类别配置为准，示例字段包括：

- 型号
- 频率范围
- 驻波比
- 法兰 / 接口
- 工作带宽
- 轴比
- 增益
- 规格书

### 6.3 移动端表格

移动端采用横向滚动表格：

- 左侧型号列使用 `position: sticky; left: 0` 固定。
- 右侧规格书列使用 `position: sticky; right: 0` 固定。
- 中间技术指标区域横向滑动。
- 表格上方提示用户可以横向滑动查看指标。
- 产品介绍和图片区域在表格前纵向排列。

## 7. 分系统集成产品的特殊展示

### 7.1 与普通产品的区别

分系统产品在后台由一个富文本编辑器维护内容，因此前台不应将内容拆分为：

- 产品介绍卡片
- 独立图片轮播组件
- 产品型号卡片
- 独立参数卡片

这些拆分会与后台内容模型不一致。

### 7.2 正确展示形式

分系统末级内容应模拟微信文章或新闻详情页：

```text
文章标题
产品型号 / 内容类型等元信息
富文本正文
正文中的标题、段落、列表、表格和图片
规格书申请入口
```

图片如果存在，只能作为富文本正文中的普通图片内容出现，不能在页面额外生成图片轮播组件。

### 7.3 当前真实目录示例

第五章“分系统集成产品”中的“卫星通信天馈伺分系统”包括：

- L、X 波段双频便携式卫星通信天馈伺系统
- X 波段车载静中通天馈伺系统
- Ku 波段静中通天馈伺系统
- X/Ku 双波段车载静中通天馈伺系统
- Ku 波段车载静中通天馈伺系统
- S 波段车载多模反射面天馈伺系统
- Ku 波段中高度动中通天馈伺系统
- 车载三频可折叠天馈伺系统

点击其中任意一个分系统后，右侧应打开文章式富文本内容，而不是普通参数表。

## 8. 当前低保真原型文件

当前低保真原型位于：

```text
docs/prototypes/hengda-product-center-low-fi.html
```

原型当前用于确认：

- 产品目录树层级
- 五级分类展开逻辑
- 同层级收缩逻辑
- 可点击面包屑
- 目录固定定位
- 普通产品参数表
- 型号技术参数弹窗
- 分系统文章式富文本详情

## 9. 高保真开发前必须确认

- 高保真目录数据必须由 `第九版手册目录24.12.17.docx` 解析生成。
- 产品目录树不能依赖原型中的手工模拟数据。
- 产品目录、面包屑、右侧子分类和路由必须共享同一份目录数据。
- 普通产品和分系统产品必须使用不同的内容展示策略。
- 分系统详情不能添加后台富文本编辑器中不存在的轮播组件。
- 产品参数表必须支持左侧型号列和右侧规格书列固定。
- 移动端必须验证目录操作和参数表横向滚动体验。
