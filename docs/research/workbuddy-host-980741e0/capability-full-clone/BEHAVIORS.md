# Behaviors

## Shared Content Area
- Static content pages with no scroll-driven or click-driven content switching.
- Header and footer are intentionally supplied by the current project, not the target site.
- Hero uses a fixed pale blue to white gradient, centered text, and breadcrumb links.
- Cards and images use hover where applicable; capability cards lift by 6px and gain a blue border and medium shadow.

## Responsive Behavior
- Desktop: 1200px content container with 24px side padding.
- Tablet: capability cards change from 3 columns to 2 columns.
- Mobile: cards and media grids stack to a single column; smart page video expands from 50% max width to full width.
