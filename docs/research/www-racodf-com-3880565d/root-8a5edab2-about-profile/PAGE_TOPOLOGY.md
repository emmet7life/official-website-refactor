# About profile topology

The fixed shared header overlays a white, grid-textured `#about` section. The content order is: section title and blue rule → tab strip → two-column profile panel. The left seven columns contain the 16:9 campus image and three paragraphs of company copy. The right three columns contain “核心企业” and “参股企业” groups of bordered company chips. The shared dark footer follows the section. Hidden modal elements remain outside the flow.
