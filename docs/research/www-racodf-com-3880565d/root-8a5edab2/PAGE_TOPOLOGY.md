# Homepage topology

Fixed SiteHeader overlays HeroSection. Flow: HeroSection, StatsSection, BusinessSection, IndustrySection, ProfileSection, AdvantagesSection, ContactSection, SiteFooter. SiteDialogs are initially hidden fixed overlays.

Desktop container maximum 1440px, including padding 64px. Tablet padding 40px; mobile 20px. Hero 100vh, minimum 560px. Original CSS utility values and responsive rules are retained alongside Tailwind v4. Original system fonts require no remote dependency.

Ten named section components correspond to ten specs. Detail-page links retain the original origin/hash; those views are outside homepage scope. No backend, authentication or tracking copied. All 20 homepage images downloaded locally.
