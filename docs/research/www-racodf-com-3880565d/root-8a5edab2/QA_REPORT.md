# 雷科防务首页还原验收

源地址：https://www.racodf.com/  
目标路由：`/`  
本次预览：http://localhost:3001/

## 交付内容

- 7 个正文区块，加导航与页脚，共 9 个页面区域。
- 11 个 React 组件、11 份组件规格，包括弹窗与交互控制器。
- 20 个本地图片素材；原站 SVG 保留在 JSX 中；采用原站系统字体。
- 完整保存三个尺寸的 DOM、逐元素计算样式、原始与还原截图、轮播状态及素材清单。
- 根路由原本是未使用的模板占位页，本次替换为首页；没有其他已有业务路由。
- 用户已有 `.agents/` 与 `skills-lock.json` 未修改。两个组件工作树的提交已合并，工作树已移除。

## 验证结果

`pnpm run check` 全部通过：ESLint 无警告、TypeScript 无错误、Next.js 生产构建成功。

| --- | --- | --- |
| 1440px | 所有区域均为 0px | 正常 |
| 768px | 所有区域均为 0px | 正常 |

高度比较基于同为 900px 视口高度下的实际 DOM 矩形，详见 `extraction-*.json` 与 `qa-*.json`。这证明区块尺寸一致，不代表对动态轮播截图做逐像素完全相等断言。

15 项浏览器行为检查通过，记录在 `qa-interactions.json`：轮播前后切换、搜索打开与匹配、结果跳转、页脚隐私弹窗、Escape 关闭、业务概览独立视图、首页恢复、空表单拦截、有效表单演示回执、移动菜单开关、中英文切换。

视觉核对已修正：原站隐藏导航项导致的移动页脚高度偏差，以及 Tailwind v3/v4 渐变变量差异造成的标题短线缺失。最终截图位于对应 `docs/design-references/` 命名空间中的 `clone-1440.png`、`clone-768.png` 和 `clone-390.png`。

## 范围与限制

- 本次还原 URL 默认首页。产品、解决方案、新闻等详情链接通往原站相应哈希视图。
- 咨询表单验证后显示明确的本地演示回执，不向原站发送数据；未实现后台或身份认证。
- 中英文切换使用原站提取的 198 条静态译文。原站 CMS 动态内容不在这份词典中的部分仍保留中文，英文版未单独进行全页视觉验收。
- 原站在 768px 下业务引导语使用不换行样式，会超出内容宽度；为忠实还原保留了该行为。
- 轮播和入场动画为动态内容，截图会受采样时刻影响；原站浏览器扩展浮标不属于网页组件。

## 复现

开发预览：`pnpm run dev`。完整检查：`pnpm run check`。

素材脚本默认仅下载/校验素材，保留已完成组件：`python scripts/download-assets-www-racodf-com-3880565d-root-8a5edab2.py`，需要 Python 与 BeautifulSoup。`--generate-components` 仅用于重新生成最初的静态基底，会覆盖同名交互组件，应在独立工作树使用。

浏览器检查脚本 `scripts/qa-racodf.py` 通过 browser-harness 执行，默认检查开发端口 3000；本次也在生产端口 3001 执行通过。
